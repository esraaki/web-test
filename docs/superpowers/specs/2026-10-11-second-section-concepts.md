# ATHAR Second-Section Concepts

Build an internal `/concepts` page that leaves the homepage untouched and presents eight fully designed section experiments in this exact order:

1. البيت يتشكّل حولك — scroll-built architectural assembly.
2. نفس المكان، ضوء مختلف — pointer-controlled time-of-day scrubber.
3. ادخل البيت — scroll-through doorway / spatial zoom.
4. المكان قبل المبنى — site-analysis overlays resolving into architecture.
5. ثلاثة قرارات — three giant interactive architectural decisions: فتحة / فناء / ظل.
6. قطاع حيّ — animated architectural section with sunlight, occupancy and room response.
7. مقياس الإنسان — architectural details at exaggerated scale resolving to the whole house.
8. لقطة واحدة بلا انقطاع — uninterrupted cinematic architectural shot with sparse timed typography.

The page is an interaction playground, not a wireframe. Each concept must have its own structure, motion language and visual treatment while still feeling compatible with ATHAR. Arabic-first RTL. Add a temporary small square ↗ tester control fixed to the homepage bottom-right linking to `/concepts`; add a return control on the concepts page.
