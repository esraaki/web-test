# ATHAR V25 Publishable Site Design

## Goal
Turn the existing cinematic Arabic concept into a believable bilingual architecture-studio website without changing the homepage structure, motion language, or bespoke visual experiments.

## Scope
- Keep the existing homepage section order and animation behavior.
- Refine Arabic copy where it is generic and provide natural English copy rather than literal translation.
- Arabic lives at `/` in RTL; English lives at `/en` in LTR.
- Add a visible AR / EN navbar switch that preserves the corresponding page where possible.
- Remove the `/concepts` lab, tester arrow, imports, routes, files, and tests.
- Add a lightweight Wadi House case-study page in both languages.
- Add a combined Studio + Contact page in both languages.
- Project CTAs link to the case study; studio/contact navigation links become functional.
- Preserve custom day/night frames, formation video, comparison assets, logo, and footer composition.
- Use a coherent premium contemporary-residential image set; avoid changing custom-built media.
- Maintain responsive desktop/mobile behavior.
